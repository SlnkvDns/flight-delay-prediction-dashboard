# Анализ и прогнозирование задержек авиарейсов

Интерактивное веб-приложение на Streamlit для изучения данных об авиарейсах и прогнозирования наличия задержки с помощью нескольких моделей машинного обучения. Проект объединяет просмотр набора данных, исследовательские визуализации и интерфейс для получения предсказаний по отдельному рейсу или загруженному CSV-файлу.

**Демо:** [salnikov-rgr-fit231.streamlit.app](https://salnikov-rgr-fit231.streamlit.app/)

## Возможности

- Просмотр исходного и подготовленного наборов данных.
- Интерактивные страницы с визуализациями распределения задержек по дням недели, длительности перелёта и корреляций признаков.
- Прогноз для одного рейса по его характеристикам.
- Пакетное прогнозирование для записей из CSV с отображением результата для каждой строки.
- Выбор одной из шести моделей: Decision Tree, Random Forest, XGBoost, Stacking, CatBoost и FCNN.

## Данные и признаки

Приложение работает с данными о рейсах. Для прогноза используются:

| Признак | Описание |
| --- | --- |
| `Airline` | Код авиакомпании |
| `Flight` | Номер рейса |
| `AirportFrom` | Код аэропорта вылета |
| `AirportTo` | Код аэропорта прибытия |
| `DayOfWeek` | День недели |
| `Time` | Время вылета в минутах от начала суток |
| `Length` | Длительность перелёта в минутах |

Целевой признак — `Delay`: наличие задержки. Категориальные признаки в подготовленном наборе закодированы числовыми значениями. В описании обработки данных также указаны удаление идентификатора и дубликатов, работа с пропусками и выбросами, а также применение SMOTE для балансировки классов.

## Технологии

- Python
- Streamlit
- pandas и NumPy

## Запуск локально

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости и запустите приложение:

```bash
pip install -r requirements.txt
streamlit run app.py
```

После запуска Streamlit выведет локальный адрес приложения в терминале.

## Использование CSV для прогнозирования

На странице **«Предсказание»** выберите модель, загрузите CSV с признаками рейсов и просмотрите таблицу с добавленным столбцом `Delay`. Формат и названия столбцов должны соответствовать признакам, используемым обученными моделями; пример файла доступен в `data/test_input_data.csv`.
